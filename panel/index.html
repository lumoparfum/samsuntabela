Galeri Paneli

samsuntabela.tr galerisini buradan yönetirsin. Girmek için GitHub erişim anahtarını yapıştır.

Anahtar nasıl alınır? (bir kez, 3 dk)
  1. Bilgisayarda github.com → sağ üst profil → Settings
  2. En altta Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
  3. Token name: Galeri Paneli · Expiration: 1 year (custom ile daha uzun seçilebilir)
  4. Repository access: Only select repositories → lumoparfum/samsuntabela
  5. Permissions → Repository permissions: Contents: Read and write, Actions: Read-only, Pages: Read-only
  6. Generate token → çıkan github_pat_… metnini kopyala, buraya yapıştır
